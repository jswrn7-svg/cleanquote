청춘클린랩 견적서 v5 · 로고 워터마크/명함/홈페이지 버튼

기존 v4의 브라우저 저장소 키를 그대로 사용합니다.
같은 웹 주소(같은 origin)에 새 파일을 덮어쓰면 기존 견적 내역과 회사 설정을 유지합니다.
다른 폴더를 file://로 직접 열거나 다른 주소로 옮기면 브라우저 저장 내역이 자동 이전되지 않습니다.
업데이트 전 반드시 기존 앱의 저장 목록 > 견적 데이터 백업(JSON)을 이용하세요.

[추가 기능]
- 제공받은 청춘클린랩 공식 로고를 기본 워터마크로 내장
- 설정 > 회사 로고 업로드 시 새 로고가 워터마크에도 적용
- 워터마크 사용 여부, 투명도, 크기, 위치 설정
- 명함 표시, 홈페이지 버튼 표시, 문구, 버튼 색상 설정
- PDF의 홈페이지 버튼에 클릭 가능한 링크 삽입
- 기존 PDF 저장/메일 공유/견적 저장 기능 유지

[사용]
1. 기존 앱의 저장 목록에서 JSON 백업
2. 기존 웹 배포 위치에 새 파일 전체를 덮어쓰기
3. 설정 탭에서 홈페이지 URL 입력, 버튼 설정 후 저장
4. 견적 작성 > PDF 저장 > PDF에서 홈페이지 버튼 클릭 테스트

주의: 실제 홈페이지 주소는 사용자가 설정해야 합니다.
