청춘클린랩 오프라인 PWA 설치 안내
=================================
1. 서버가 전혀 필요 없는 '운영' 방식이지만 최초 PWA 설치와 서비스 워커 등록은 HTTPS 웹 호스팅 또는 localhost가 필요합니다. 갤럭시에서 ZIP을 풀고 file://로 index.html을 열면 PWA 설치/오프라인 캐시가 정상 작동하지 않습니다.
2. GitHub Pages 등 정적 HTTPS 호스팅에 이 폴더의 파일 전체(index.html, style.css, app.js, sw.js, manifest.webmanifest, icons)를 업로드하세요. 서버 프로그램이나 DB, 도메인 구매는 필요하지 않습니다. 무료 정적 호스팅의 공개 URL은 누구나 접속할 수 있으므로 앱 자체에 관리자 인증이 없다는 점을 유의하세요.
3. 갤럭시 Chrome에서 HTTPS 주소로 접속하고 메뉴(점 3개) > 홈 화면에 추가 > 설치를 선택합니다. 메뉴는 기기/버전에 따라 다를 수 있습니다.
4. 온라인 상태에서 첫 화면을 한 번 연 뒤에는 오프라인에서도 견적 작성, 저장, PDF 생성이 가능합니다. 이메일 공유/발송에는 인터넷과 메일 앱이 필요합니다.
5. '메일 공유'는 Android 공유 시트에 PDF 파일을 넘깁니다. 네이트 메일 앱이 PDF 첨부 공유를 지원하지 않으면 PDF 저장 후 네이트 메일 앱에서 직접 첨부하세요. 자동 SMTP 전송은 지원하지 않습니다.
6. 데이터는 갤럭시의 브라우저 로컬 저장소에 보관됩니다. '저장 목록 > 견적 데이터 백업'을 주기적으로 실행하세요. 브라우저 데이터 삭제/앱 제거/기기 분실 시 데이터가 사라질 수 있습니다.
7. 보안: 고객 정보는 브라우저 저장소에 암호화되지 않은 형태로 보관됩니다. 화면 잠금이 설정된 개인 휴대전화에서만 사용하세요. 다른 업체에 공개 배포할 경우 개인정보처리방침과 보안 검토가 필요합니다.
8. PDF는 기기 내 Canvas로 한글을 렌더링한 이미지 기반 PDF입니다. 한글은 표시되지만 PDF 안에서 텍스트 검색/선택은 불가능합니다. 기존 Windows v11 PDF 디자인과 동일하지 않습니다.
9. 앱 업데이트 시 브라우저가 새 서비스워커 캐시를 가져와야 하므로 sw.js의 CACHE 값을 변경하세요.

[v6 변경] 청소 작업 범위를 번호 배지와 교차 배경 카드로 표시하고 줄 간격을 확장했습니다. 기존 줄바꿈 입력을 항목별로 구분하며 길면 자동 줄바꿈/페이지 넘김합니다. PWA 캐시 버전 업데이트.
