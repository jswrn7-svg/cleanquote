청춘클린랩 견적서 PWA v7 — 공통 추가 안내사항

[추가 기능]
설정 → 모든 견적서 공통 안내사항 → 문구 입력 → 회사 · 담당자 정보 저장
공통 안내사항 자동 포함을 체크하면 PDF의 05 추가 안내에 자동 삽입됩니다.
견적 작성 → 견적별 추가 안내사항은 해당 견적서에만 표시됩니다.
공통 안내문이 비어 있으면 출력하지 않습니다. 공통 안내문만 있어도 05 추가 안내가 표시됩니다.
기존 견적 저장 구조, 로고 워터마크, 명함, 홈페이지 버튼, PDF, 백업 기능은 유지합니다.

[업데이트 주의]
기존 PWA를 사용 중이라면 먼저 저장 목록에서 견적 데이터 백업(JSON)을 만드세요.
기존과 같은 웹 주소에 배포해야 브라우저 저장소의 기존 견적을 이어 쓸 수 있습니다.
앱을 제거하거나 사이트 데이터를 삭제하면 기존 견적이 지워질 수 있습니다.
