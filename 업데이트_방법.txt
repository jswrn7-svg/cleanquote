청춘클린랩 PWA v2 PDF/메일 공유 수정본

1. ZIP 압축 해제
2. GitHub 저장소 jswrn7-svg/cleanquote 에서 Add file → Upload files
3. 압축 해제한 index.html, app.js, style.css, sw.js, manifest.webmanifest, icons 폴더 전체 업로드
4. 같은 이름 파일 변경 확인 후 Commit changes
5. GitHub Pages 배포 완료 후 갤럭시 Chrome에서 페이지 새로고침 또는 앱 종료 후 재실행
6. PDF 저장 시 내 파일 → 다운로드에서 열기
7. 메일 공유는 갤럭시 공유 메뉴에서 네이트 메일 앱 선택 (네이트 앱이 PDF 파일 공유를 지원해야 함)

주의: 서버 없는 GitHub Pages에서는 네이트 SMTP 자동발송을 지원하지 않습니다. 네이트 비밀번호를 JS에 넣지 마세요.
기존 로컬 저장 견적 내역은 같은 도메인/브라우저를 유지하면 일반적으로 보존되지만 업데이트 전 JSON 백업 권장.
